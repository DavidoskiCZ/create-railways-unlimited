## [0.1.0-beta.2] - 2026-11-08

### Added
- Mod icon.
- The mod list links to the GitHub page and the issue tracker.

### Changed
- Requires NeoForge 21.1.219 or newer (was 21.1.265), so the mod also runs in older 1.21.1 modpacks.

## [0.1.0-beta.1] - 2026-11-08

First public beta.

### Added
- Straight track at 5°, 15°, 30° or 45° steps, set per player and per world (goggles + track + **G**).
- Turns like Create's: the smallest one, or the widest with **Left Control**.
- **Left Alt** for straight track, **Y** to keep the height, **X** to keep the grade.
- Slopes that join like Create's: free ends lie flat, joints tilt when the hill continues.
- Stations, signals and trains on angled track; Create Track Map draws it without gaps.
- Goggle overlay with the angle, step and grade; survival track cost shown like in Create.
- Steam 'n' Rails: the preview shows wide / narrow gauge and monorail.
- Debug tools: show joints, remove "ghost" track graph nodes around the player.

### Known limitations
- Trains are assembled on 0°/45° track (as in Create), but stop at stations on angled track.
- Girders and paving are not applied to angled pieces yet.
- Angled track cannot start from or end on Create's steep slope blocks.
